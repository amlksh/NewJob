# 웹 데모 샘플 (컨셉 목업)

`index.html` — **의존성 없는 단일 파일**. 더블클릭하면 브라우저에서 바로 실행됩니다.

## 무엇을 보여주나
가상 조립 라인 위로 부품이 흐르고, AI 카메라 지점을 지날 때마다:
1. **인지** — 부품을 스캔
2. **판단** — 이상 점수(Anomaly Score) 산출
3. **행동** — 점수에 따라 대응을 자동 선택 (통과 / 경고 / 라인 정지 / 담당자 호출)

중대 이상이면 라인이 실제로 멈추고, 이상 부위에 히트맵이 표시됩니다.

## 조작
- **▶ 시작**: 라인 가동
- **⏸ 일시정지 / ↻ 재가동**: 정지된 라인 복구
- **⚠ 이상 부품 투입**: 결함 부품을 강제로 흘려보내 대응을 시연 (발표 시 유용)
