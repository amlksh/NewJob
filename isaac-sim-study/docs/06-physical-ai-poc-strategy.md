# 06. Physical AI PoC 전략 — 조립 라인 이상감지·대응 에이전트

> 목적: 6개월 뒤 "간단하지만 제가 직접 만든 Physical AI PoC입니다"를 보여줄 수 있는 상태.
> 확정 방향: **이상감지·대응 에이전트** · 도메인 **제조 조립 라인** · 자산 **불확실(토이 병행)** · 역량 **Python 보통 / 주 5~10h**.

## 0. 한 줄 포지셔닝

> **"디지털트윈팀은 무대(공장)를 만들고, 나는 그 안에서 보고·판단·행동하는 AI를 만든다."**

트윈팀과 경쟁이 아니라 **곱하기** 관계. 그들의 3D 공장을 *지능이 도는 공장*으로 바꿔서
그들의 결과물 가치를 올리는 동시에 대체 불가능한 자리를 잡는다.
용어는 의도적으로 **"Physical AI"**(NVIDIA Omniverse + Isaac + 합성데이터 + sim-to-real)를 쓴다.

## 1. PoC 정의: 조립 라인 이상감지·대응 에이전트

비전문가가 1분 안에 이해하고, "AI가 **스스로 판단하고 행동했다**"가 눈에 보여야 한다.

**루프: 감시(인지) → 이상 감지·분류(판단) → 이상 종류별 대응 선택(행동)**

- **인지**: 조립 라인을 보는 고정 카메라(+필요 시 센서) 스트림을 감시.
- **판단**: 정상 패턴을 학습해 이상을 감지하고 **종류를 분류**
  (예: 부품 누락 / 오부착 / 위치 틀어짐 / 라인 정지·정체).
- **행동(에이전트의 핵심)**: 이상 *종류·심각도에 따라 다른 대응을 스스로 선택*.
  - 경미 → 로그 + 경고 표시
  - 중대 → 라인 정지 신호 + 리젝트 + 알람
  - 모호 → 사람 호출(스냅샷 첨부)

> "검사기"는 정상/불량만 외친다. **"에이전트"는 무엇을 할지 고른다.** 이 차이가
> 당신이 원하는 "판단하고 행동하는 AI"의 증거이고, 데모에서 가장 인상적인 순간이다.

### 전략의 심장: 합성 데이터
현실 검사 AI의 최대 벽 = **이상 데이터가 없다**(드물고·비싸고·라벨링 고통).
트윈이 있으니 뒤집는다:

> **"트윈 안에서 이상 상황을 무한히 합성해(Isaac Sim Replicator) AI 에이전트를 학습시켰습니다."**

- 회장님이 기억하는 문장이 된다.
- 트윈 자산이 "예쁜 3D" → **"데이터 공장"**으로 격상 (트윈팀이 나를 좋아할 이유).
- NVIDIA Physical AI의 교과서 스토리(synthetic data → sim-to-real).

→ 생성 방법은 [07. Replicator 합성 데이터 가이드](07-replicator-synthetic-data.md) 참고.

## 2. 기술 스택 (Python 보통 = "조립 + 약간의 작성")

| 구성 | 선택 | 이유 |
|------|------|------|
| 환경 | Isaac Sim + 토이 조립 제품/라인 + 고정 카메라 | 실제 USD는 M5 업그레이드 |
| 데이터 | **Isaac Sim Replicator** | 정상/이상 이미지 + 자동 라벨, 조명·각도·위치 랜덤화 |
| 판단(감지) | **이상탐지(Anomaly Detection)** 우선 | 정상 샘플만으로 학습 → 데이터 부담 최소. 라이브러리: Anomalib |
| 판단(분류) | 간단 분류기/검출기 (선택) | 이상 *종류* 구분이 필요할 때. YOLO 등 |
| **행동(에이전트)** | **대응 정책 레이어** (규칙/상태기계 → 가벼운 로직) | 이상 종류·심각도 → 대응 매핑. PoC의 차별점 |
| 리포트(선택) | LLM/VLM 자연어 사고 보고 | "무엇이·왜·내가 무엇을 했는지" 한 줄 요약 = 강력한 데모 |
| 연동(선택) | ROS 2 | 라인 정지/리젝트 신호를 실제 토픽으로 |

> 모델 팁: 이상탐지는 **Anomalib**(GitHub `anomalib`, Intel)처럼 설정 중심 라이브러리를 쓰면
> 학습/추론을 거의 config로 끝낼 수 있다. 객체검출이 필요하면 **Ultralytics YOLO**가 자료가 가장 많다.

## 3. 6개월 로드맵

| 기간 | 목표 | 산출물 |
|------|------|--------|
| **M1** | Isaac Sim 설치·GUI·USD 감각 (가이드 [01](01-installation.md)~[03](03-usd-structure.md)) | 토이 조립 제품 씬 + 카메라 배치, 이미지 캡처 |
| **M2** | **Replicator로 합성 데이터셋 생성**(정상/이상, 랜덤화) → [07](07-replicator-synthetic-data.md) | 자동 라벨 데이터셋 + 정상/이상 폴더 구조 |
| **M3** | 이상탐지 모델 학습 + 추론 | **이상을 잡아내는 모델** ← 최소 성공선 |
| **M4** | **대응 정책 레이어 추가**(이상 종류→대응 선택) + 루프 완성 | **감지→판단→대응 엔드투엔드 에이전트 데모** |
| **M5** | (선택) 실제 라인 USD/카메라 연결, LLM 사고 리포트, 안정화 | 더 그럴듯한 데모 |
| **M6** | 데모 영상 + 회장님용 1페이지 내러티브 | 발표 패키지 |

**원칙: M3 끝 = 보여줄 게 있는 상태. M4 끝 = "에이전트"라 부를 수 있는 상태.**
항상 "지금 당장 보여줄 수 있는 버전"을 유지한다.

## 4. 위험과 차단

| 위험 | 차단법 |
|------|--------|
| 트윈 USD 자산 불확실 | **토이 조립 씬으로 시작.** 실제 USD는 블로커가 아니라 M5 업그레이드 |
| 범위 폭주 | **부품 1종 + 이상 2~3종 + 대응 3단계**로 고정. 확장은 성공 후 |
| 시간 제약(주 5~10h) | 모델 밑바닥 구현 금지. Anomalib/예제 복사·수정 중심 |
| 화려함 유혹(LLM·RL) | 핵심 루프(M4) 완성 전에는 손대지 않는다. LLM 리포트는 M5 보너스 |

## 5. 포지셔닝(정치) 무브

- **트윈팀을 아군으로.** "당신들 트윈으로 데이터를 만들어 AI가 돌게 했다" — 그들의 공로를 키운다.
- **점진적 공유.** M3·M4에서 작은 데모를 미리 보여 신뢰를 쌓는다(6개월 침묵 후 한 방 ✗).
- **언어 통일.** 보고/대화에서 "Physical AI / 합성데이터 / 자율 에이전트"를 일관되게 사용.
- **1페이지 내러티브 미리 써두기.** 기술이 아니라 *문제→해결→결과* 순서로.

## 6. 회장님용 1페이지 골격 (미리 채워두기)

1. **문제**: 조립 라인 이상은 드물어서 *데이터가 없고*, 사람이 24시간 다 볼 수 없다.
2. **착안**: 우리에겐 디지털 트윈이 있다 → 이상을 합성해 AI를 가르치면 된다.
3. **한 일**: 트윈에서 이상 상황 합성 → AI 에이전트 학습 → 트윈 안에서 실시간 감지·**대응**.
4. **결과(데모)**: 조립 이상이 발생하자 AI가 스스로 종류를 판단하고 라인을 멈추는 30초 영상.
5. **다음**: 실제 라인 카메라/USD로 확장, 이상 종류 추가, 대응 자동화 → 실제 도입 로드맵.
