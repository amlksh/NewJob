# Physical AI PoC 제안 보고서

### 가상공장에서 스스로 판단·행동하는 AI 에이전트

---

## 1. 한 줄 요약

> **디지털 트윈(가상공장) 안에서 조립 라인의 이상을 스스로 감지하고, 종류에 따라 대응까지 결정하는 AI 에이전트를 직접 구축합니다. 6개월 내 동작 PoC 시연을 목표로 합니다.**

## 2. 배경 — 왜 지금인가

- **Physical AI**(현실 세계를 인지·판단·행동하는 AI)가 제조업의 다음 경쟁축으로 부상하고 있습니다. (NVIDIA Omniverse·Isaac 생태계 중심)
- 우리는 이미 **디지털 트윈(가상공장)** 자산을 보유하고 있습니다. 이는 경쟁사 대비 **출발점에서 앞선 위치**입니다.
- 그러나 트윈이 "보는 것"에 머물면 가치가 제한됩니다. **그 안에서 판단하고 행동하는 지능**을 얹을 때 비로소 차별화됩니다.
- 리스크: 관심만 있고 착수하지 않으면, 시장이 움직였을 때 따라가는 입장이 됩니다. **작더라도 직접 만든 PoC**가 가장 확실한 대응입니다.

## 3. 제안 — 무엇을 만드는가

**제조 조립 라인 이상감지·대응 에이전트** (디지털 트윈 내)

| 단계 | 동작 |
|------|------|
| **인지** | 조립 라인 카메라 영상을 실시간 감시 |
| **판단** | 정상 패턴을 학습해 이상(부품 누락·오부착·위치 이탈 등)을 감지·분류 |
| **행동** | 이상의 종류·심각도에 따라 **대응을 스스로 선택** (통과 / 경고 / 라인 정지 / 담당자 호출) |

> 단순 "검사기"가 아니라, **무엇을 할지 결정하는 에이전트**라는 점이 핵심입니다.

## 4. 핵심 차별점 — 합성 데이터

현실의 이상탐지 AI는 **"이상 데이터가 없다"**(드물고·비싸고·라벨링 어려움)는 벽에 부딪힙니다.
우리는 이 문제를 **디지털 트윈으로 뒤집습니다.**

> **트윈 안에서 이상 상황을 무한히 합성(Synthetic Data)해 AI를 학습시킵니다.**

- 트윈 자산이 "예쁜 3D"에서 **"AI 학습 데이터 공장"**으로 격상됩니다.
- 디지털트윈팀의 성과 가치를 함께 키우는 **협업 구조**입니다.
- NVIDIA가 제시하는 Physical AI 표준 전략(synthetic data → 현실 적용)을 그대로 따릅니다.

## 5. 기대 효과

- **단기**: 회사 내 Physical AI 실증 역량 확보 (직접 구축한 PoC 보유)
- **중기**: 실제 라인 카메라 연결 시 **품질 이상 자동 감지·대응**으로 확장 가능
- **전략**: "트윈을 가진 회사" → **"트윈 위에서 지능이 도는 회사"**로 포지셔닝

## 6. 6개월 로드맵

| 기간 | 목표 | 산출물 |
|------|------|--------|
| 1개월 | 환경·기초 (Isaac Sim, USD) | 조립 제품 가상 씬 + 카메라 |
| 2개월 | 합성 데이터 생성 | 정상/이상 학습 데이터셋 |
| 3개월 | 이상탐지 모델 | **이상을 잡아내는 AI** (최소 성과) |
| 4개월 | 대응 에이전트 | **감지→판단→대응 엔드투엔드 시연** |
| 5개월 | 고도화 (실라인 연결·안정화) | 데모 품질 향상 |
| 6개월 | 시연 패키지 | **30초 데모 영상 + 발표 자료** |

> 3개월 차에 이미 "보여줄 수 있는 결과"가 나오며, 4개월 차에 "에이전트"가 완성됩니다.

## 7. 데모 시나리오 (6개월 후 시연 장면)

1. 가상 조립 라인이 정상 가동 중
2. 이상 부품(예: 커넥터 누락) 등장
3. AI가 즉시 감지 → 화면에 이상 부위 **히트맵 표시**
4. AI가 **"라인 정지"를 스스로 결정** → 가상 컨베이어 정지
5. **"담당자 호출"** 알림 (이상 스냅샷 첨부)

> 30초면 비전문가도 "AI가 보고, 판단하고, 행동했다"를 이해할 수 있습니다.

## 8. 요청 사항

- 디지털트윈팀과의 **트윈 자산(조립 라인 USD) 공유 협조**
- RTX GPU 워크스테이션 1대 (Isaac Sim 구동 필수 사양)
- 6개월간 본 PoC에 대한 **시간 배정 및 추진 승인**
