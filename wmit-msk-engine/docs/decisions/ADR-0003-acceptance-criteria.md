# ADR-0003: 품질 지표 합격기준

- 상태: **미결정** — P1 에서 문헌 근거로 확정, G1 승인 대상
- 일자: 2026-09-22
- 결정자: TBD

## 배경

파이프라인은 마커 RMS 오차, 잔차력, 잔차모멘트를 산출한다.
이 값이 얼마 이하여야 결과를 쓸 수 있는지 정해야 한다.

**이 ADR 이 확정되기 전까지 `configs/cases/*.yaml` 의 임계값은 `TBD` 로 둔다.**
코드는 `TBD` 를 `undecided` 로 기록하고 판정을 내리지 않는다. 임의의 숫자를 기본값으로 넣지 않는다.

## 확정 절차

1. OpenSim 공식 가이드와 관련 문헌에서 통용 기준을 수집한다. 출처를 이 문서에 인용한다.
2. Grand Challenge 튜닝용 trial 로 PoC 를 돌려 실제 달성 가능한 수준을 확인한다.
3. 잔차는 절대값보다 체중·피험자 규모로 정규화하는 편이 타당한지 검토한다.
4. 1~3 을 근거로 값을 제안하고 G1 에서 승인받는다.
5. 승인된 값을 `configs/cases/*.yaml` 의 `thresholds` 에 반영한다.

## 주의

- 달성된 결과에 맞춰 기준을 사후에 느슨하게 고치지 않는다. 기준을 못 맞추면 그 사실을 V&V 결과서에 적는다.
- 검증용 trial 의 결과를 보고 기준을 조정하면 검증이 아니다. 기준은 검증 전에 고정한다.
