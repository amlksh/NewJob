# ADR-0001: OpenSim 기준 버전을 4.6 으로 한다

- 상태: **제안** (G1 에서 확정)
- 일자: 2026-09-22
- 결정자: TBD (VPK PLM기술팀 / WMIT 공동)

## 배경

서버에서 헤드리스로 돌릴 OpenSim 버전을 정해야 한다.
버전이 바뀌면 결과 수치가 달라질 수 있어 V&V 재수행이 필요하므로, 초기에 고정한다.

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| 4.6 | 공식 PyPI wheel 제공(Linux 포함), 최신 기능·수정 반영, 강성 시스템용 CPodes 적분기 | JAM 등 외부 포크 호환성 미확인 |
| 4.5 | 사용 사례·문헌이 많음 | PyPI 패키지 없음(Conda 전용), Conda Moco 패키지는 Windows 한정 |
| 소스 빌드 | 완전한 제어 | 빌드·유지보수 부담, 재현성 확보에 추가 작업 |

## 결정

**OpenSim 4.6 + PyPI wheel** 을 기준으로 한다.

근거:
- 4.6 부터 공식 PyPI 패키지가 제공되며, Linux(glibc 2.27+ / x86-64) wheel 이 Python 3.11–3.13 으로 배포된다. 컨테이너 구성이 한 줄로 끝난다.
- 4.5 는 Conda 전용이고, Moco 포함 Conda 패키지는 Windows 한정이어서 Linux 서버 배포에 불리하다.
- 라이선스는 Apache 2.0 으로 상업적·정부과제 이용에 제약이 없다 (모델·플러그인은 별도, 라이선스 대장 참조).

## 영향

- 실행 환경 기준은 `docker/Dockerfile` (python:3.11-slim-bookworm, glibc 2.36).
- WMIT 서버 OS 가 구형이어도 컨테이너로 격리되므로 영향받지 않는다.
- 버전 변경 시 V&V 활동 V-01 ~ V-05 를 재수행한다.

## 미해결

- [ ] OpenSim-JAM 포크가 4.6 에서 빌드되는지 (P1, `poc/jam/`)
- [ ] WMIT 서버에서 컨테이너 실행이 허용되는지 (P0)
