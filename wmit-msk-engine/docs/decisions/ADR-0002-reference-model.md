# ADR-0002: 1차 Reference 무릎 모델 선정

- 상태: **결정 대기** — 사용자 확인 필요
- 일자: 2026-09-22
- 결정자: TBD (VPK PLM기술팀 / WMIT 공동)

## 배경

무릎 해석 모델에는 성격이 다른 두 갈래가 있고, 1차 범위와 일정이 여기서 갈린다.

## 선택지

| 선택지 | 산출물 | 장점 | 단점 |
| --- | --- | --- | --- |
| Rajagopal 계열 전신 모델 | 관절각, 모멘트, 근육력, 관절반력 | 표준 워크플로와 호환, 문헌 많음, 유지보수 부담 적음 | 인대력·연골 접촉압 산출 불가 |
| OpenSim-JAM (Lenhart2015 + COMAK) | 위 + 인대력, 연골 접촉압 | 무릎 상세 역학, 임플란트 평가에 더 가까움 | 별도 포크 기반이라 4.6 호환성 미확인, 설정·계산 부담 큼 |
| 둘 다 1차 포함 | — | 범위 넓음 | P2 가 1~2개월 늘어남, G1 지연 위험 |

## 권고안

**Rajagopal 계열을 1차 기본으로 확정하고, JAM 은 `poc/jam/` 에서 호환성 시험(PoC)만 병행한다.**

근거:
- 1차 완료 기준은 "무릎 가상환자 해석을 웹에서 실행"이며, 관절반력까지면 이를 만족한다.
- 관절반력은 향후 Abaqus 연계 시 FE 경계조건으로 그대로 쓰인다. 접촉압은 FE 쪽에서 더 정확히 얻는다.
- JAM 의 4.6 호환성이 확인되지 않은 상태에서 이를 1차 경로에 넣으면 일정 위험이 크다.

## 영향

- 이 결정에 따라 `configs/cases/` 의 `model_file` 과 `required_markers` 가 정해진다.
- JAM 을 1차에 포함하면 V&V 추적표에 인대력·접촉압 QoI 를 추가하고 검증 활동을 늘려야 한다.
